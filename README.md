### 🗄️ Legacy Archive

shalaREPO was originally made to host a collection of Roothide/Bootstrap compatible tweaks in one place. This was helpful before tools like NathanLR on iOS versions like 17.0 that didn't yet support SpringBoard injection. Now that SpringBoard has been accomplished, such tweaks are no longer needed. The older tweaks been archived so that they aren't in the way, however, they **remain installable**. Add shalaREPO on a device running an arm64e jailbreak to access these archived tweaks.
