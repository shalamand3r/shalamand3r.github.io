### arm64e Archive

shalaREPO was originally created to host a collection of RootHide/Bootstrap-compatible tweaks in one place. This was especially useful before tools like NathanLR, when iOS versions such as 17.0 did not yet support SpringBoard injection. Now that SpringBoard injection has been accomplished, these tweaks are *technically* no longer needed. The older tweaks have been archived so they stay out of the way, but they **remain installable**.

Add shalaREPO on a device running an arm64e jailbreak to access the archived tweaks.
